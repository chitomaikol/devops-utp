Proyecto de un reloj estilo pixel art para la clase de DevOps.

Instrucciones:
- abre index.html en el navegador, o
- ejecuta `python -m http.server 8000` dentro de esta carpeta y visita http://localhost:8000
una pruebas de los cambios

init: significa que vamos a inicializar el git en la carpeta que nosotros tenemos abierta
add: sirve para adicionar nuestros cambios o archivos nuevos, quedan en espera para subir
commit: sireve para dejar un comentario sobre los cambios que hemos hecho para saber que fue lo que hicimos en el comentario
push: sirve para aplicar los cambios hechos en local y subirlos al git en la nube
status: para evidenciar en que estado estan los archivos o cambios que hemos hecho, si estan en local o en la nube o cuales estan pendientes por subir
diff: para revisar que es lo que esta pendiente y los cambios que hemos hecho en local y en la nube 
log: sirve para ver el historico de los commits que hemos hecho
